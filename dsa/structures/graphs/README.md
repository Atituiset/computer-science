# 图

> 图是 DSA 里**抽象层次最高**的部分. 想清楚一道题是不是"图问题", 往往就能瞬间看出 O(...) 在哪: 是不是边集的形态 (稠密/稀疏)、是不是有负权、是不是要支 odp. 几乎所有"独立单元 + 关联"的工程题 (依赖关系、链路、调度), 背后都是图问题.
