# 贪心

## 核心: 可贪心 ⟺ 最优子结构 + 无后效性

- 当前选最优且未来不会被推翻 ⇒ 局部最优可拼接为全局最优.
- 严格证明常用 **交换论证**: 把任意最优解"调整"成贪心解时不劣反而可能更优.
- 或者用 **induction**: 假设前 k 步贪心与 OPT 一致, 证 第 k+1 步贪心也能保持.

## 经典 CN 模板

- **活动选择 / 区间调度**: 按 end 排序, 取最早结束的, 去掉重叠;
- **Huffman 编码**: 每次合并最小频次两堆, 证明见任何算法书;
- **最小生成树 Kruskal**: 贪边;
- **Dijkstra**: 贪距离;
- **任务调度 SPT (Shortest Processing Time first)**: 总等待时间最短.

## 工程里什么时候能用贪心

1. 输入很有结构 (如区间、双值);
2. 你能构造**凸性**: 例如 leveling 系统的"花最少的钱升级", 前提是升级代价凸函数;
3. 没有结构? 老实 DP / 回溯.

## 易错

1. **依据排序"长"判区间调度**: 常见错误按 start 排序; 正确是按 end.
2. **认为"看起来对就行"**: 贪心几乎从不重做"句型证", 少了证明就易出反例. 最好用 1~2 个反例自检.
3. **"贪 + DP"**: 比如背包问题中部分背包是贪心 (按 unit value 排序); 但 0/1 背包必须 DP. 区分关键.
