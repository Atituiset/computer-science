1. Shannon Entropy: 离散源熵 / 联合熵 / 条件熵 / 互信息 ​

TL;DR ​

熵 H(X)H(X)H(X) = 信源 XXX 的平均不确定度 (字 bit-by-bit 平 TG 系统 coap 联接中, 必分布在平均未发生" leagues 触少 MB; something. per second waiting ). 它是:

H(X)=−∑xp(x)log⁡2p(x)H(X) = -\sum_{x} p(x) \log_2 p(x) H(X)=−x∑​p(x)log2​p(x)

扩展到联合 (H(X,Y)H(X, Y)H(X,Y)), 条件 (H(Y∣X)H(Y|X)H(Y∣X)), 互信息 I(X;Y)=H(X)−H(X∣Y)I(X;Y) = H(X) - H(X|Y)I(X;Y)=H(X)−H(X∣Y) 即"因为我已知 XXX, YYY 的不确定减少了多少". 熵是所有后续章节 (压缩极限, 容量) 的源头.

一、为什么用 −log⁡p-\log p−logp ​

Shannon 一开始提"信息量" I(x)=−log⁡2p(x)I(x) = -\log_2 p(x)I(x)=−log2​p(x): 概率小的事件发生让我们"惊讶大", 信息量大. 几个 desirable properties 唯一确定:

  1. I(x)≥0I(x) \geq 0I(x)≥0.
  2. I(x)I(x)I(x) 随 p→0p \to 0p→0 → ∞\infty∞.
  3. I(x)=0I(x) = 0I(x)=0 iff p(x)=1p(x) = 1p(x)=1.
  4. 独立事件叠加: I(x,y)=I(x)+I(y)I(x, y) = I(x) + I(y)I(x,y)=I(x)+I(y) if independent.

唯一 fff 满足所有: f(x)=−log⁡bxf(x) = -\log_b xf(x)=−logb​x (任意对数底). 默认 b=2b = 2b=2 取 bit.

期望: H(X)=E[I(X)]=−∑p(x)log⁡p(x)H(X) = E[I(X)] = -\sum p(x) \log p(x)H(X)=E[I(X)]=−∑p(x)logp(x).

二、Examples 起手 ​

2.1 公平硬币 + 高度偏: ​

  • Fair coin: H=−2⋅(1/2)log⁡(1/2)=1H = -2 \cdot (1/2) \log(1/2) = 1H=−2⋅(1/2)log(1/2)=1 bit.
  • Loaded coin P(H)=0.99P(H)=0.99P(H)=0.99: H=−0.99log⁡0.99−0.01log⁡0.01≈0.081H = -0.99 \log 0.99 - 0.01 \log 0.01 \approx 0.081H=−0.99log0.99−0.01log0.01≈0.081 bit.

→ 偏源册的熵远低 (实际每 toss 真正"惊喜"少).

2.2 ASCII 英文 ​

英文 26 字母 (空格 + punctuation) variate 很多: empirical 熵 (字天然统计) H≈4.5H \approx 4.5H≈4.5 bit/char 但 raw 8 bit/char ⇒ 冗余 44%.

Shannon 1951 估 English word (条件 char-by-char) 实际熵 ≈1.3 bit/char ⇒ 总冗余 84%.

→ 这就是英文 真可压缩到 1/6 原文 size, 实现上 zstd / brotli 接到 1/4 ~ 1/5 之 size.

2.3 Python 计算 ​

python
from collections import Counter
from math import log2

def empirical_entropy(text: str) -> float:
    counts = Counter(text)
    n = len(text)
    return -sum(c / n * log2(c / n) for c in counts.values())

print(empirical_entropy("the quick brown fox jumps over the lazy dog"))
# ~4.4 bit/char

三、联合熵 H(X,Y)H(X, Y)H(X,Y) ​

H(X,Y)=−∑x,yp(x,y)log⁡p(x,y)H(X, Y) = -\sum_{x, y} p(x, y) \log p(x, y) H(X,Y)=−x,y∑​p(x,y)logp(x,y)

是, 即同时出现"X 取 xxx 且 Y 取 yyy"的不确定度.

3.1 性质 ​

  • H(X,Y)≤H(X)+H(Y)H(X, Y) \leq H(X) + H(Y)H(X,Y)≤H(X)+H(Y) (subj. 独立时取等).
  • H(X,Y)=H(Y,X)H(X, Y) = H(Y, X)H(X,Y)=H(Y,X) (对称).
  • H(X,Y)≥max⁡(H(X),H(Y))H(X, Y) \geq \max(H(X), H(Y))H(X,Y)≥max(H(X),H(Y)) (knowing 不会 make more uncertain).

四、条件熵 H(Y∣X)H(Y|X)H(Y∣X) ​

H(Y∣X)=∑xp(x)H(Y∣X=x)=−∑x,yp(x,y)log⁡p(y∣x)H(Y|X) = \sum_x p(x) H(Y|X=x) = -\sum_{x, y} p(x, y) \log p(y|x) H(Y∣X)=x∑​p(x)H(Y∣X=x)=−x,y∑​p(x,y)logp(y∣x)

"已知 XXX 的情况下 YYY 还剩多少不确定".

4.1 链式法则 ​

H(X,Y)=H(X)+H(Y∣X)H(X, Y) = H(X) + H(Y|X) H(X,Y)=H(X)+H(Y∣X)

Example: XXX = "今日天气", YYY = "明天天气". H(X,Y)=H(X)+H(Y∣X)H(X, Y) = H(X) + H(Y|X)H(X,Y)=H(X)+H(Y∣X) = "今日不确定 + 已知今日的明日增量".

4.2 信息不在 XXX 完美预测 YYY ​

  • 若 Y=f(X)Y = f(X)Y=f(X) 确定性: H(Y∣X)=0H(Y|X) = 0H(Y∣X)=0.
  • 反之 X⊥YX \perp YX⊥Y: H(Y∣X)=H(Y)H(Y|X) = H(Y)H(Y∣X)=H(Y).

4.3 性质 ​

  • H(Y∣X)≤H(Y)H(Y|X) \leq H(Y)H(Y∣X)≤H(Y) (knowing XXX 不会增加 YYY 不确定).

五、互信息 I(X;Y)=H(X)−H(X∣Y)=H(Y)−H(Y∣X)I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)I(X;Y)=H(X)−H(X∣Y)=H(Y)−H(Y∣X) ​

十、Maximum Entropy Principle ​
