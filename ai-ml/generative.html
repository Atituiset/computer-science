5. Generative Models: VAE & ELBO / 扩散模型 / AR 采样 / speculative decoding ​

TL;DR ​

"生成模型"是把概率分布 p(x)p(x)p(x) 当学习目标的一类模型. 直接学高维 p(x)p(x)p(x) 不估计动, 所以四套主流方案分别走不同路:

  1. Autoregressive (AR) / GPT 风 — p(x)=∏tp(xt∣x<t)p(x) = \prod_t p(x_t | x_{<t})p(x)=∏t​p(xt​∣x<t​).
  2. Flow / Normalizing Flow — 用可逆变换把简单高斯推向复杂数据分布.
  3. VAE — 引入隐变量 zzz, 最大化 ELBO (等价最小化 reverse-KL).
  4. 扩散模型 (Diffusion) — 加噪声 + 学去噪; ELBO 推到 Gaussian NLL 简化为 (ϵ−ϵθ)2(\epsilon - \epsilon_\theta)^2(ϵ−ϵθ​)2.

本章把这四类原理 + ELBO 数学一气讲透, 并补上采样加速工程: KV cache、temperature/top-k/top-p、speculative decoding.

读完应能: 读 VAE 原 paper (Kingma 2013) / DDPM (Ho 2020) / Speculative Decoding (Leviathan 2022) 不再卡数学, 在 NumPy 上写出最简 VAE 与扩散训练循环.

一、统一视角: 生成模型 = 概率分布拟合 ​

1.1 真实目标 ​

数据集 {xi}i=1n\{x_i\}_{i=1}^n{xi​}i=1n​ 视为某未知分布 pdata(x)p_{\text{data}}(x)pdata​(x) 的样本. 训练目标:

arg⁡max⁡θEx∼D[log⁡pθ(x)] \arg\max_\theta \mathbb{E}_{x \sim \mathcal{D}} [\log p_\theta(x)] argθmax​Ex∼D​[logpθ​(x)]

即最大似然, 回顾第零部分概率 §5.

1.2 为什么 MLE 不够? ​

对复杂数据 (图像 / 文本), 直接定义 pθ(x)p_\theta(x)pθ​(x) 并求它是难事. 解决方案:

  • AR: 把 p(x)p(x)p(x) 分解为 ∏p(xt∣x<t)\prod p(x_t | x_{<t})∏p(xt​∣x<t​), 每一项可参数化为神经网络输出.
  • Flow: 通过可逆变化把 x∼pθ⇔z∼N(0,I)x \sim p_\theta \Leftrightarrow z \sim \mathcal{N}(0, I)x∼pθ​⇔z∼N(0,I), 用 change-of-variables.
  • VAE: 引隐变量 zzz, 学一个 encoder qϕ(z∣x)q_\phi(z|x)qϕ​(z∣x) 与 decoder pθ(x∣z)p_\theta(x|z)pθ​(x∣z), 联合似然 = ELBO.
  • Diffusion: 让 zzz 有层级意义 (x0,x1,…,xTx_0, x_1, \ldots, x_Tx0​,x1​,…,xT​ 渐噪化), encoder 是固定 forward process, decoder 是学 reverse process.

二、Autoregressive (AR) 采样 ​

2.1 概率链 ​

pθ(x1:T)=∏t=1Tpθ(xt∣x<t) p_\theta(x_{1:T}) = \prod_{t=1}^{T} p_\theta(x_t | x_{<t}) pθ​(x1:T​)=t=1∏T​pθ​(xt​∣x<t​)

每项参数化 = transformer decoder 的下一个 token 分布; 损失 = next-token CE (回顾 §3 Transformer).

2.2 与 NLL 的等价 ​

每步的负对数似然 = log⁡V−log⁡pθ(xt∣x<t)\log V - \log p_\theta(x_t | x_{<t})logV−logpθ​(xt​∣x<t​). perplexity = exp⁡(avgNLL)\exp(\mathrm{avgNLL})exp(avgNLL), 一个常报指标.

2.3 采样 ​

python
def sample(model, prompt, n=64, temperature=1.0, top_p=0.9):
    ids = list(prompt)
    for _ in range(n):
        logits = model(ids)            # 取 last position logits
        logits = logits[-1] / temperature
        # top-p / nucleus
        sorted_l = np.sort(logits)[::-1]; cumprobs = np.cumsum(softmax(sorted_l))
        cutoff = np.searchsorted(cumprobs, top_p)
        kept = sorted_l[:cutoff + 1]
        probs = softmax(kept); next_id = np.random.choice(kept.shape[0], p=probs)
        ids.append(next_id)
    return ids

2.4 采样超参的数学含义 ​

超参行为直觉
T→0T \to 0T→0argmax贪心 / 确定输出
T=1T = 1T=1原分布真样本
T→∞T \to \inftyT→∞均匀创造性最满
Top-k留 k 个最高 logits 余归一限制样本在常见 token
Top-p (nucleus)累积概率到 p 的最少 token动态阈值

TIP

经验上 LLM 任务: T=0.7∼1.0T = 0.7 \sim 1.0T=0.7∼1.0, top-p = 0.9 ~ 0.95, 适合开放式对话; 代码生成更低温 T=0.1∼0.4T = 0.1 \sim 0.4T=0.1∼0.4. 不随意把 TTT 提高 → 让 LLM 像随机 token generator.

2.5 KV cache: 自回归推理加速 ​

L 步推理: 第 ttt 步每将 xtx_txt​ 与所有 x<tx_{<t}x<t​ 算 attention, kt,vtk_t, v_tkt​,vt​ 不变 → 缓存 KV 矩阵 仅计算新一步.

显存: 一卡 LLM 推理主要被 KV 占 (而非权重), 故 PagedAttention / MLA / 量化 KV 成工业核心.

四、VAE: ELBO = reverse KL ​

4.1 模型 ​

设隐变量 zzz, 含 pθ(x,z)=p(z)pθ(x∣z)p_\theta(x, z) = p(z) p_\theta(x|z)pθ​(x,z)=p(z)pθ​(x∣z). 真实后验 pθ(z∣x)p_\theta(z | x)pθ​(z∣x) 不可积, 用近似 qϕ(z∣x)q_\phi(z | x)qϕ​(z∣x):

log⁡pθ(x)=log⁡∫pθ(x,z) dz \log p_\theta(x) = \log \int p_\theta(x, z) \, dz logpθ​(x)=log∫pθ​(x,z)dz

Jensen 不等式 + 加 form:

log⁡pθ(x)=Ez∼qϕ(z∣x)[log⁡pθ(x,z)qϕ(z∣x)]+KL(qϕ(z∣x)∥pθ(z∣x)) \log p_\theta(x) = \mathbb{E}_{z \sim q_\phi(z|x)} \left[ \log \frac{p_\theta(x, z)}{q_\phi(z|x)} \right] + \mathrm{KL}(q_\phi(z|x) \| p_\theta(z|x)) logpθ​(x)=Ez∼qϕ​(z∣x)​[logqϕ​(z∣x)pθ​(x,z)​]+KL(qϕ​(z∣x)∥pθ​(z∣x))

第一项是 ELBO (Evidence Lower Bound), 第二项 ≥0\geq 0≥0. 最大化 ELBO ⇔ 最小化 KL(qϕ∥pθ(z∣x))\mathrm{KL}(q_\phi \| p_\theta(z|x))KL(qϕ​∥pθ​(z∣x)).

ELBO 拆开:

LELBO=Ez∼qϕ(z∣x)[log⁡pθ(x∣z)]−KL(qϕ(z∣x) ∥ p(z)) \mathcal{L}_{\text{ELBO}} = \mathbb{E}_{z \sim q_\phi(z|x)} \big[\log p_\theta(x|z)\big] - \mathrm{KL}\big(q_\phi(z|x) \,\|\, p(z)\big) LELBO​=Ez∼qϕ​(z∣x)​[logpθ​(x∣z)]−KL(qϕ​(z∣x)∥p(z))

  • 第一项 = 重建项 (decoder likelihood).
  • 第二项 = KL 正则项 (encoder 不偏离 prior 多少).

NOTE

这就是 VAE 训练目标: max ELBO. 第零部分概率 §7 KL 不对称很关键 — 通过 reverse-KL (q∥pq \| pq∥p) 让 qqq 倾向 mode-seeking, 但在多模态真实后验下会缺一些质量.

4.2 重参数技巧 (reparameterization) ​

直接采 z∼N(μ,σ2)z \sim \mathcal{N}(\mu, \sigma^2)z∼N(μ,σ2) 不可反传 (随机节点). 改写:

z=μ+σ⊙ϵ,ϵ∼N(0,I) z = \mu + \sigma \odot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I) z=μ+σ⊙ϵ,ϵ∼N(0,I)

→ μ,σ\mu, \sigmaμ,σ 变 deterministic, 蒙特卡洛用同一 batch 多次采样.

4.3 VAE 训练循环 (PyTorch 简版) ​

python
import torch
import torch.nn as nn
import torch.nn.functional as F

class VAE(nn.Module):
    def __init__(self, d_x=784, d_z=20, d_h=400):
        super().__init__()
        self.enc = nn.Sequential(nn.Linear(d_x, d_h), nn.ReLU())
        self.fc_mu = nn.Linear(d_h, d_z); self.fc_logvar = nn.Linear(d_h, d_z)
        self.dec = nn.Sequential(nn.Linear(d_z, d_h), nn.ReLU(), nn.Linear(d_h, d_x), nn.Sigmoid())

    def encode(self, x):
        h = self.enc(x); return self.fc_mu(h), self.fc_logvar(h)

    def reparam(self, mu, logvar):
        std = (0.5 * logvar).exp()
        return mu + std * torch.randn_like(std)

    def decode(self, z): return self.dec(z)

    def forward(self, x):
        mu, logvar = self.encode(x); z = self.reparam(mu, logvar)
        return self.decode(z), mu, logvar

def vae_loss(x_recon, x, mu, logvar):
    BCE = F.binary_cross_entropy(x_recon, x, reduction='sum')     # -E[log p(x|z)]
    KLD = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())  # KL(N(μ,σ²) || N(0, 1))
    return BCE + KLD

TIP

VAE 的"模糊"问题 — 重建项用 BCE/MSE 对应 Bernoulli/Gaussian decoder; 模糊因为高斯 decoder 平均多个模态. 加 GAN 判别器 / 改输出分布变 mixture / 改扩散走法解决.

五、扩散模型 (DDPM) ​

5.1 核心思想 ​

把数据 x0x_0x0​ 在 TTT 步里逐步加高斯噪声:

q(xt∣xt−1)=N(xt;1−βtxt−1,βtI) q(x_t | x_{t-1}) = \mathcal{N}(x_t; \sqrt{1 - \beta_t} x_{t-1}, \beta_t I) q(xt​∣xt−1​)=N(xt​;1−βt​​xt−1​,βt​I)

联合的有 closed-form:

q(xt∣x0)=N(xt;αˉtx0,(1−αˉt)I),αˉt=∏s=1t(1−βs) q(x_t | x_0) = \mathcal{N}(x_t; \sqrt{\bar\alpha_t} x_0, (1 - \bar\alpha_t) I), \quad \bar\alpha_t = \prod_{s=1}^t (1 - \beta_s) q(xt​∣x0​)=N(xt​;αˉt​​x0​,(1−αˉt​)I),αˉt​=s=1∏t​(1−βs​)

→ 任意 ttt 可从 x0x_0x0​ 一步采样 (训时常用).

5.2 反向过程 (用网络学) ​

pθ(xt−1∣xt)=N(xt−1;μθ(xt,t),Σθ(xt,t)) p_\theta(x_{t-1} | x_t) = \mathcal{N}(x_{t-1}; \mu_\theta(x_t, t), \Sigma_\theta(x_t, t)) pθ​(xt−1​∣xt​)=N(xt−1​;μθ​(xt​,t),Σθ​(xt​,t))

5.3 ELBO 推到简化形式 ​

DDPM 原 paper 推导完整 ELBO, 设 Σθ=βtI\Sigma_\theta = \beta_t IΣθ​=βt​I 固定得到项:

Lt−1=Eq[βt22σt2αtβt∥μ^θ(xt,t)−μq(xt,x0)∥2] \mathcal{L}_{t-1} = \mathbb{E}_q \left[ \frac{\beta_t^2}{2 \sigma_t^2 \alpha_t \beta_t} \|\hat\mu_\theta(x_t, t) - \mu_q(x_t, x_0)\|^2 \right] Lt−1​=Eq​[2σt2​αt​βt​βt2​​∥μ^​θ​(xt​,t)−μq​(xt​,x0​)∥2]

进一步 reparameterize 让网络预测"原始噪声" ϵ\epsilonϵ 而非 μ\muμ:

Ltsimple=Ex0,ϵ,t∥ϵ−ϵθ(αˉtx0+1−αˉtϵ,t)∥2 \mathcal{L}_t^{\text{simple}} = \mathbb{E}_{x_0, \epsilon, t} \big\| \epsilon - \epsilon_\theta(\sqrt{\bar\alpha_t} x_0 + \sqrt{1 - \bar\alpha_t} \epsilon, t) \big\|^2 Ltsimple​=Ex0​,ϵ,t​​ϵ−ϵθ​(αˉt​​x0​+1−αˉt​​ϵ,t)​2

NOTE

工业训练: 输入网络 xt=αˉtx0+1−αˉtϵx_t = \sqrt{\bar\alpha_t} x_0 + \sqrt{1 - \bar\alpha_t} \epsilonxt​=αˉt​​x0​+1−αˉt​​ϵ (前闭式), 预测噪声 ϵ\epsilonϵ 与真 ϵ\epsilonϵ 做 MSE. 这就是为什么所有"扩散训练循环"看起来这么朴素.

5.4 训练循环 (PyTorch 简版) ​

python
import torch.nn as nn

class Diffusion(nn.Module):
    def __init__(self, model, T=1000, betas=None):
        super().__init__()
        self.model = model                      # ε_θ(x_t, t)
        self.T = T
        if betas is None:
            betas = torch.linspace(1e-4, 0.02, T)
        alphas = 1.0 - betas
        self.register_buffer('alphas_cumprod', torch.cumprod(alphas, 0))

    def forward_loss(self, x0):
        B = x0.shape[0]
        t = torch.randint(0, self.T, (B,), device=x0.device)
        eps = torch.randn_like(x0)
        a_bar = self.alphas_cumprod[t].view(B, 1, 1, 1)
        x_t = a_bar.sqrt() * x0 + (1 - a_bar).sqrt() * eps
        eps_pred = self.model(x_t, t)
        return nn.functional.mse_loss(eps_pred, eps)

5.5 采样: 慢的分步去噪 ​

python
@torch.no_grad()
def sample(self, shape):
    x = torch.randn(shape)
    for t in reversed(range(self.T)):
        eps_pred = self.model(x, torch.full((shape[0],), t))
        alpha = self.alphas[t]; alpha_bar = self.alphas_cumprod[t]
        x0_pred = (x - (1 - alpha_bar).sqrt() * eps_pred) / alpha_bar.sqrt()
        x = alpha.sqrt() * x0_pred + (1 - alpha).sqrt() * torch.randn_like(x) if t > 0 else x0_pred
    return x

DDPM 1000 步采样太慢, DDIM (Song 2021) 用非 Markov 跳步采样 50 步质量近似. 进一步:

  • DPM-Solver (Lu 2022): 10-25 步高质量采样.
  • Consistency Models (Song 2023): 1 步采样.
  • Latent Diffusion (Stable Diffusion 2022): 在 VAE latent 上扩散, 而非像素 → 大幅省算工程盈利.

六、Speculative Decoding (LLM 推理加速) ​

6.1 动机 ​

LLM 生成时每 token 一次 forward pass, GPU 利用率低. 用一个草稿小模型先猜 kkk 个 token, 再用大模型一次 forward 验证.

6.2 算法 ​

  1. draft model MdM_dMd​ 自回归生成 kkk 个候选 token x1:kx_{1:k}x1:k​.
  2. target model MtM_tMt​ 用 同一 prompt + kkk token 做一次 forward, 得到各位置分布 p1:ktp_{1:k}^tp1:kt​.
  3. 对每位置 iii, 比较 xix_ixi​ 在 pitp_i^tpit​ 与 pidp_i^dpid​ 的概率:
    • 若 pit(xi)≥pid(xi)p_i^t(x_i) \geq p_i^d(x_i)pit​(xi​)≥pid​(xi​): accept.
    • 若 pit(xi)<pid(xi)p_i^t(x_i) < p_i^d(x_i)pit​(xi​)<pid​(xi​): 以 (1−pit(xi)pid(xi))\left(1 - \frac{p_i^t(x_i)}{p_i^d(x_i)}\right)(1−pid​(xi​)pit​(xi​)​) 概率拒绝, 拒绝则从残余概率 ∝pit−pid\propto p_i^t - p_i^d∝pit​−pid​ 重采一个新 token.
  4. 拒后丢弃后续.

6.3 数学保证 ​

分布与原 target model 严格相同 (rejection sampling correctness). 因此生成不变, 只是更快 (草稿准 → 接受多 → 每 forward 吐多 token).

6.4 工程增益 ​

  • accepted fraction 0.5-0.7 时 2-3× speedup.
  • 与 KV cache 兼容: draft 与 target 共用 KV cache 接口, 同步多条 path.
  • 与 Medusa / EAGLE / Lookahead 等扩展思路是不同分支预测方案.

WARNING

speculative decoding 的核心是概率分布一致性而非单纯接受率. 工程上仔细处理 torch.distribution.Independent、rejection 不能简化成 argmax == argmax, 否则会漫游偏离原分布.
