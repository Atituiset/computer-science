4. 微积分与最优化: 链式法则 / 雅可比 / Hessian / 凸优化 / 信息几何 ​

TL;DR ​

优化是计算机科学里"反向"的一面: 用前向 (compiles 哪些到哪些) 算"loss", 再用反向 (链式法则) 算"该怎么改参数让 loss 更小". Transformer、信息论容量推导、调度器最短作业先选、HP 计算代价模型本质都是同一件事: 在光滑空间里取梯度. 这一篇覆盖:

  1. 极限与导数 — 微分与差分的连续 / 离散切换.
  2. 链式法则 + 多元函数 + 雅可比矩阵 — Transformer 反向传播的硬公式.
  3. Hessian + 泰勒展开 + 二阶方法 — 极值附近的曲率信号.
  4. 凸函数 / 凸优化 — 优化领域的"快 + 全局最优"区间.
  5. 梯度下降 / Stochastic / Momentum / Adam — 工业优化器谱系.
  6. 拉格朗日 + KKT — 带约束优化的标准框架.
  7. 信息几何 — 用 KL / Fisher 度量把"分布空间"做成流形, 推出自然梯度与变分推断.

目标: 看到 Adam、EM、$\nabla_\phi \mathbb{E}[\ldots]$、$\Lambda \succeq 0$ 不再卡.

2.1 偏导数与方向导数 ​

f:Rn→Rf: \mathbb{R}^n \to \mathbb{R}f:Rn→R 的偏导 ∂f/∂xi\partial f / \partial x_i∂f/∂xi​. 梯度:

∇f(x)=(∂f∂x1,…,∂f∂xn)⊤ \nabla f(\boldsymbol x) = \left(\frac{\partial f}{\partial x_1}, \ldots, \frac{\partial f}{\partial x_n}\right)^\top ∇f(x)=(∂x1​∂f​,…,∂xn​∂f​)⊤

方向 v\boldsymbol vv 上的方向导数 = ∇f⋅v/∥v∥\nabla f \cdot \boldsymbol v / \|\boldsymbol v\|∇f⋅v/∥v∥; 沿梯度方向取最大. 即"梯度下降合理性"的数学.

2.2 复合与雅可比 ​

设 g:Rn→Rmg: \mathbb{R}^n \to \mathbb{R}^mg:Rn→Rm, f:Rm→Rf: \mathbb{R}^m \to \mathbb{R}f:Rm→R. 复合 h=f∘g:Rn→Rh = f \circ g: \mathbb{R}^n \to \mathbb{R}h=f∘g:Rn→R:

∂h∂x=∇f(g(x))⊤⏟1×m⋅Jg(x)⏟m×n \frac{\partial h}{\partial \boldsymbol x} = \underbrace{\nabla f(g(\boldsymbol x))^\top}_{1 \times m} \cdot \underbrace{J_g(\boldsymbol x)}_{m \times n} ∂x∂h​=1×m∇f(g(x))⊤​​⋅m×nJg​(x)​​

JgJ_gJg​ 即雅可比矩阵, [Jg]ij=∂gi/∂xj[J_g]_{ij} = \partial g_i / \partial x_j[Jg​]ij​=∂gi​/∂xj​.

Transformer 反向传播就是矩阵化 + 反序的链式法则: 每一层的"loss 对输入梯度"= 该层输出梯度乘该层权重梯度.

2.3 softmax 雅可比 ​

s=softmax(z)\boldsymbol s = \mathrm{softmax}(\boldsymbol z)s=softmax(z):

∂si∂zj={si(1−si)i=j−sisji≠j \frac{\partial s_i}{\partial z_j} = \begin{cases} s_i (1 - s_i) & i = j \\ -s_i s_j & i \neq j \end{cases} ∂zj​∂si​​={si​(1−si​)−si​sj​​i=ji=j​

向量形式 Jsoftmax=diag(s)−ss⊤J_{\mathrm{softmax}} = \mathrm{diag}(s) - s s^\topJsoftmax​=diag(s)−ss⊤.

工程意义: 反向传 (ds)=J⋅dz(\boldsymbol{ds}) = J \cdot \boldsymbol{dz}(ds)=J⋅dz 即 ds=s⊙(dz−(s⊤dz)1)\boldsymbol{ds} = s \odot (\boldsymbol{dz} - (s^\top \boldsymbol{dz})\mathbf{1})ds=s⊙(dz−(s⊤dz)1).

2.4 反向传播 (autograd 模式) ​

python
import numpy as np
# 简化的两层数值梯度校验
def softmax_ce(logits, y):
    z = logits - logits.max(axis=-1, keepdims=True)
    e = np.exp(z); s = e / e.sum(axis=-1, keepdims=True)
    return -np.log(s[y] + 1e-12)

def grad_softmax_ce(logits, y):
    s = np.exp(logits - logits.max()) / np.exp(logits - logits.max()).sum()
    g = s.copy(); g[y] -= 1
    return g    # 简化: 对 logit 的导数 = (σ - onehot)

关键观察: 交叉熵 + softmax 的反传结果是 (s−1y)(s - \mathbf{1}_y)(s−1y​), 这条公式出现在每个 softmax 分类器里. 记下来一辈子省试错.

2.5 数值方法: 自动求导 ​

  • 前向模式 AD: 一个变量求偏导链, O(n) 算一个分量.
  • 反向模式 AD: 一次反向跑出所有偏导, O(1) 算 loss 对所有参数 (gradient). 这就是 PyTorch 默认反向 (TensorFlow tf.GradientTape).

TIP

反向 AD 是 1970 Linnainmaa 发现 + 1986 Rumelhart-Hinton-Williams popularized. 现代 DL 能训参数 101110^{11}1011 都是它的功劳. 写"反向传播"不是推每个 dot; 而是按计算图节点按拓扑逆序局部求导.

三、Hessian 与二阶 ​

3.1 二阶偏导 ​

Hf(x)ij=∂2f∂xi∂xj H_f(\boldsymbol x)_{ij} = \frac{\partial^2 f}{\partial x_i \partial x_j} Hf​(x)ij​=∂xi​∂xj​∂2f​

HHH 是对称矩阵 (若 fff 充分光滑). 在 stationary ∇f=0\nabla f = 0∇f=0 处:

  • H≻0H \succ 0H≻0 ⇒ 局部最小.
  • H≺0H \prec 0H≺0 ⇒ 局部最大.
  • 不定 ⇒ 鞍点.
  • 半正定/半负定 ⇒ 二阶检验不足, 需高阶.

3.2 泰勒展开 (2D 局部) ​

f(x+h)≈f(x)+∇f(x)⊤h+12h⊤Hf(x)h f(\boldsymbol x + \boldsymbol h) \approx f(\boldsymbol x) + \nabla f(\boldsymbol x)^\top \boldsymbol h + \frac{1}{2} \boldsymbol h^\top H_f(\boldsymbol x) \boldsymbol h f(x+h)≈f(x)+∇f(x)⊤h+21​h⊤Hf​(x)h

含义: 沿一阶方向线性近似; 二阶项表达曲率. 这就是 Newton 法、Trust-region、CG、BFGS 的全部来源.

3.3 Newton 迭代 ​

xk+1=xk−Hf−1(xk)∇f(xk) \boldsymbol x_{k+1} = \boldsymbol x_k - H_f^{-1}(\boldsymbol x_k) \nabla f(\boldsymbol x_k) xk+1​=xk​−Hf−1​(xk​)∇f(xk​)

优点: 二次收玫 (近最优时极快). 缺点: 求 (n×n)H−1(n \times n) H^{-1}(n×n)H−1 太贵, HHH 可能 ill-conditioned. 工程变体:

  • 拟牛顿 BFGS / L-BFGS: 用历史梯度更新 H−1H^{-1}H−1 近似.
  • 共轭梯度 CG: 只需 HHH × 向量乘法.

3.4 为什么深度学习不用 Newton? ​

  • 参数维度 n∼109n \sim 10^9n∼109, H∈R109×109H \in \mathbb{R}^{10^9 \times 10^9}H∈R109×109 显然太贵.
  • 非凸+随机性 ⇒ 一阶 SGD 经验反而更好+可 scale.
  • 反向传播比求逆便宜太多.

→ 这就是 Adam 之类一阶方法的现实位置.

四、凸优化 ​

4.1 凸函数 ​

凸集 S⊆RnS \subseteq \mathbb{R}^nS⊆Rn: ∀x,y∈S,λ∈[0,1]\forall \boldsymbol x, \boldsymbol y \in S, \lambda \in [0, 1]∀x,y∈S,λ∈[0,1]: λx+(1−λ)y∈S\lambda \boldsymbol x + (1-\lambda) \boldsymbol y \in Sλx+(1−λ)y∈S.

凸函数 f:S→Rf: S \to \mathbb{R}f:S→R:

f(λx+(1−λ)y)≤λf(x)+(1−λ)f(y) f(\lambda \boldsymbol x + (1-\lambda)\boldsymbol y) \leq \lambda f(\boldsymbol x) + (1-\lambda)f(\boldsymbol y) f(λx+(1−λ)y)≤λf(x)+(1−λ)f(y)

判定: 一阶 (凸) ∇2f⪰0\nabla^2 f \succeq 0∇2f⪰0.

凸优化强:

  • 任何局部最小 = 全局最小.
  • KKT 条件充要 (约束情形).
  • 多项式时间可达 ϵ\epsilonϵ-optimal (Interior Point).

NOTE

即使损失非凸, 工程上常见"局部凸": 在 good init 周围 Hessian 半正定, Newton / GD 仍可以收敛到本地区的最优. 这是 NTM、LoRA fine-tune 的"为什么调一调就 OK".

4.3 拉格朗日对偶 ​

原问题 min⁡f(x) s.t. gi(x)≤0,hj(x)=0\min f(\boldsymbol x) \text{ s.t. } g_i(\boldsymbol x) \leq 0, h_j(\boldsymbol x) = 0minf(x) s.t. gi​(x)≤0,hj​(x)=0:

L(x,λ,ν)=f(x)+∑iλigi(x)+∑jνjhj(x) \mathcal{L}(\boldsymbol x, \boldsymbol\lambda, \boldsymbol\nu) = f(\boldsymbol x) + \sum_i \lambda_i g_i(\boldsymbol x) + \sum_j \nu_j h_j(\boldsymbol x) L(x,λ,ν)=f(x)+i∑​λi​gi​(x)+j∑​νj​hj​(x)

对偶函数 g(λ,ν)=inf⁡xLg(\lambda, \nu) = \inf_x \mathcal{L}g(λ,ν)=infx​L. главная trick: 最大化对偶 ⇒ 上界原问题最优. 弱对偶恒, 强对偶凸+slater 条件.

4.4 KKT 条件 ​

最优 x∗\boldsymbol x^*x∗ 满足:

  1. Stationarity: ∇f+∑iλi∇gi+∑jνj∇hj=0\nabla f + \sum_i \lambda_i \nabla g_i + \sum_j \nu_j \nabla h_j = 0∇f+∑i​λi​∇gi​+∑j​νj​∇hj​=0.
  2. Primal feasibility: gi≤0,hj=0g_i \leq 0, h_j = 0gi​≤0,hj​=0.
  3. Dual feasibility: λi≥0\lambda_i \geq 0λi​≥0.
  4. Complementary slackness: λigi(x∗)=0\lambda_i g_i(\boldsymbol x^*) = 0λi​gi​(x∗)=0.

→ SVM 的推导从这里来; 因凸, KKT 充要.

4.5 LP / QP / SDP ​

LP:  min c^T x  s.t. Ax = b, x ≥ 0            (单纯形 / interior point)
QP:  min (1/2)x^T Q x + c^T x  s.t.  linear  (Q ≥ 0 ⇒ 凸)
SDP: min c^T x  s.t. F_0 + Σx_i F_i ⪰ 0      (矩阵半正定约束)

应用: LP 调度/路由; QP 投资组合 / SVM; SDP 控制论 / PhyLayer 检验扩展 Lyapunov.

五、迭代一阶优化器谱系 ​

5.1 梯度下降 (GD) ​

xk+1=xk−η∇f(xk) \boldsymbol x_{k+1} = \boldsymbol x_k - \eta \nabla f(\boldsymbol x_k) xk+1​=xk​−η∇f(xk​)

  • η\etaη 小 ⇒ 慢但稳; 大 ⇒ 震荡可能发散.
  • 收敛分析: η≤1/L\eta \leq 1/Lη≤1/L 时凸 LLL-smooth ⇒ fk−f∗=O(1/k)f_k - f^* = O(1/k)fk​−f∗=O(1/k).

5.2 SGD (Robbins-Monro 1951) ​

每次用 mini-batch 估计 ∇f≈g^k\nabla f \approx \hat g_k∇f≈g^​k​:

xk+1=xk−ηkg^k \boldsymbol x_{k+1} = \boldsymbol x_k - \eta_k \hat g_k xk+1​=xk​−ηk​g^​k​

学习速率 schedule: ∑ηk=∞,∑ηk2<∞\sum \eta_k = \infty, \sum \eta_k^2 < \infty∑ηk​=∞,∑ηk2​<∞ ⇒ a.s. 收敛 (Robbins-Monro).

5.3 Momentum / Nesterov ​

Momentum 在梯度方向添加"惯性":

vk+1=βvk−η∇f(xk),xk+1=xk+vk+1 v_{k+1} = \beta v_k - \eta \nabla f(\boldsymbol x_k), \quad \boldsymbol x_{k+1} = \boldsymbol x_k + v_{k+1} vk+1​=βvk​−η∇f(xk​),xk+1​=xk​+vk+1​

Nesterov 加速: 先用 xk+βvk\boldsymbol x_k + \beta v_kxk​+βvk​ 评估梯度.

直觉: 沿一致方向加速, 沿高频噪声阻尼. 凸情形 Nesterov 给最优 O(1/k2)O(1/k^2)O(1/k2) 速率.

5.4 RMSProp ​

E[g2]k=αE[g2]k−1+(1−α)gk2,xk+1=xk−ηE[g2]k+ϵgk \mathbb{E}[g^2]_k = \alpha \mathbb{E}[g^2]_{k-1} + (1-\alpha) g_k^2, \quad \boldsymbol x_{k+1} = \boldsymbol x_k - \frac{\eta}{\sqrt{\mathbb{E}[g^2]_k + \epsilon}} g_k E[g2]k​=αE[g2]k−1​+(1−α)gk2​,xk+1​=xk​−E[g2]k​+ϵ​η​gk​

关键观察: 不同参数维度, 不同尺度梯度自适应 → Adam 接近 "1 个 axis 1 个步长".

5.5 Adam (Kingma & Ba 2014) ​

mk=β1mk−1+(1−β1)gk m_k = \beta_1 m_{k-1} + (1-\beta_1) g_k mk​=β1​mk−1​+(1−β1​)gk​

vk=β2vk−1+(1−β2)gk2 v_k = \beta_2 v_{k-1} + (1-\beta_2) g_k^2 vk​=β2​vk−1​+(1−β2​)gk2​

m^k=mk1−β1k,v^k=vk1−β2k \hat m_k = \frac{m_k}{1 - \beta_1^k}, \quad \hat v_k = \frac{v_k}{1-\beta_2^k} m^k​=1−β1k​mk​​,v^k​=1−β2k​vk​​

xk+1=xk−ηm^kv^k+ϵ \boldsymbol x_{k+1} = \boldsymbol x_k - \eta \frac{\hat m_k}{\sqrt{\hat v_k} + \epsilon} xk+1​=xk​−ηv^k​​+ϵm^k​​

  • 默认 β1=0.9,β2=0.999,ϵ=10−8\beta_1 = 0.9, \beta_2 = 0.999, \epsilon = 10^{-8}β1​=0.9,β2​=0.999,ϵ=10−8.
  • 动量 + RMSprop 合一; bias correction 针对初始时刻.
  • ML 中 99% 任务用 Adam 即可跑出 baseline.
python
def adam_update(params, grads, m, v, t, lr=1e-3, b1=0.9, b2=0.999, eps=1e-8):
    for p, g in zip(params, grads):
        m[p] = b1 * m[p] + (1 - b1) * g
        v[p] = b2 * v[p] + (1 - b2) * g * g
        m_hat = m[p] / (1 - b1 ** t)
        v_hat = v[p] / (1 - b2 ** t)
        p -= lr * m_hat / (v_hat.sqrt() + eps)   # 高级 pseudocode
    return params, m, v

WARNING

Adam 标准实现的"收敛证明" (Reddi et al. 2018) 发现初版收敛不严, 改进如 AMSGrad / AdamW 解决. 现代 Transformer 训练几乎全用 AdamW (decoupled weight decay), 不用 vanilla Adam.

六、信息几何 ​

6.1 分布空间作流形 ​

参数族 {pθ:θ∈Θ}\{p_\theta: \theta \in \Theta\}{pθ​:θ∈Θ}, 一个分布对应一个参数点. Fisher 信息矩阵:

I(θ)ij=Ex∼pθ[∂log⁡pθ∂θi∂log⁡pθ∂θj] \mathcal{I}(\theta)_{ij} = \mathbb{E}_{x \sim p_\theta}\left[\frac{\partial \log p_\theta}{\partial \theta_i} \frac{\partial \log p_\theta}{\partial \theta_j}\right] I(θ)ij​=Ex∼pθ​​[∂θi​∂logpθ​​∂θj​∂logpθ​​]

直觉: Fisher 信息 = "你能用数据区分参数变化的灵敏度". 实际 I=−E[Hlog⁡p]\mathcal{I} = -\mathbb{E}[H_{\log p}]I=−E[Hlogp​] (期望负 Hessian).

6.2 KL 看作曲率 ​

对参数 θ\thetaθ 微扰 dθd\thetadθ, KL 散度局部展开:

KL(pθ∥pθ+dθ)=12dθ⊤I(θ)dθ+o(∥dθ∥2) \mathrm{KL}(p_\theta \| p_{\theta + d\theta}) = \frac{1}{2} d\theta^\top \mathcal{I}(\theta) d\theta + o(\|d\theta\|^2) KL(pθ​∥pθ+dθ​)=21​dθ⊤I(θ)dθ+o(∥dθ∥2)

→ Fisher 矩阵就是分布参数空间的黎曼度量.

6.3 自然梯度 ​

普通梯度下降不看度量; 用 Fisher 修正:

θk+1=θk−η⋅Ik−1gk \theta_{k+1} = \theta_k - \eta \cdot \mathcal{I}_k^{-1} g_k θk+1​=θk​−η⋅Ik−1​gk​

直觉: 让"参数行进一步"在分布空间等价 (而不是欧式). 在 KL 时 θ\thetaθ 的大变化不一定 = ppp 的大变化, 自然梯度把它校正.

→-policy gradient 变体如 TRPO / PPO 的原理, 自然梯度约束 KL≤δ\mathrm{KL} \leq \deltaKL≤δ.

6.4 ELBO = KL 反向最小 ​

变分推断要找近似 qϕq_\phiqϕ​ 拟合 p(z∣x)p(z | x)p(z∣x). 写 ELBO:

L(ϕ)=Eqϕ[log⁡p(x,z)]−Eqϕ[log⁡qϕ(z)] \mathcal{L}(\phi) = \mathbb{E}_{q_\phi}[\log p(x, z)] - \mathbb{E}_{q_\phi}[\log q_\phi(z)] L(ϕ)=Eqϕ​​[logp(x,z)]−Eqϕ​​[logqϕ​(z)]

最大化 L\mathcal{L}L ⇔ 最小化 KL(qϕ∥pz∣x)\mathrm{KL}(q_\phi \| p_{z|x})KL(qϕ​∥pz∣x​). VAE 解码器就是这么训.

NOTE

信息几何 + Bayesian 推断 + KL 散度是一件事的三个名: 在统计参数空间用 Fisher 内积做梯度下降,(reverse-)KL 是 Riemannian metric 赋值.
