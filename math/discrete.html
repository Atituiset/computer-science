一、命题与谓词逻辑 ​

1.1 命题联结词 ​

联结符号真值表
非¬P\neg P¬P翻转
与P∧QP \land QP∧Q同真
或P∨QP \lor QP∨Q至少一真
蕴含P⇒QP \Rightarrow QP⇒Q"若 P 则 Q"; 只在 P 真 Q 假时为假
等价P⇔QP \Leftrightarrow QP⇔Q同真假
异或P⊕QP \oplus QP⊕Q不同真

工程翻译:

  • if (P) {...} 的前置条件是 ¬P\neg P¬P 表示"程序不变式未维护".
  • &&, || 短路求值 (P∧QP \land QP∧Q 在 P 假时 Q 不必算) ⊆ 严格命题逻辑.
  • 异或 ⊕\oplus⊕ 是密码学奇偶检验、FEC parity、CRC 的核心.

P⇒Q  ≡  ¬P∨Q  ≡  ¬Q⇒¬P(逆否) P \Rightarrow Q \;\equiv\; \neg P \lor Q \;\equiv\; \neg Q \Rightarrow \neg P \quad (\text{逆否}) P⇒Q≡¬P∨Q≡¬Q⇒¬P(逆否)

¬(P∧Q)  ≡  ¬P∨¬Q(De Morgan) \neg(P \land Q) \;\equiv\; \neg P \lor \neg Q \qquad \text{(De Morgan)} ¬(P∧Q)≡¬P∨¬Q(De Morgan)

1.3 谓词逻辑: 量词 ​

加入"对所有 / 存在":

  • ∀x∈S:P(x)\forall x \in S: P(x)∀x∈S:P(x) — 对所有 xxx 满足.
  • ∃x∈S:P(x)\exists x \in S: P(x)∃x∈S:P(x) — 至少一个满足.

否定翻转量词 (这是最容易出错的):

¬(∀x:P(x))  ≡  ∃x:¬P(x) \neg \big( \forall x: P(x) \big) \;\equiv\; \exists x: \neg P(x) ¬(∀x:P(x))≡∃x:¬P(x)

¬(∃x:P(x))  ≡  ∀x:¬P(x) \neg \big( \exists x: P(x) \big) \;\equiv\; \forall x: \neg P(x) ¬(∃x:P(x))≡∀x:¬P(x)

例: ∀T∈Threads:safe(T)\forall T \in \text{Threads}: \text{safe}(T)∀T∈Threads:safe(T) 的反面是"∃T\exists T∃T 不safe", 即"有 bug 时的反例".

1.4 与程序的不变式 ​

Hoare 三元组 {P} S {Q}\{P\}\ S\ \{Q\}{P} S {Q}: 若执行前 PPP 真, 则 SSS 终止后 QQQ 真.

最弱前置条件 wp(S,Q)\mathrm{wp}(S, Q)wp(S,Q) 是所有使 SSS 终止后满足 QQQ 的最弱前置. Dijkstra 用它做了程序演算, 把程序证明转为公式演算.

def fib_fast(n: int) -> int:
    # 矩阵快速幂: [[1,1],[1,0]]^n = [[F_{n+1}, F_n],[F_n, F_{n-1}]]
    def mul(A, B):
        return [[A[0][0]*B[0][0] + A[0][1]*B[1][0],
                 A[0][0]*B[0][1] + A[0][1]*B[1][1]],
                [A[1][0]*B[0][0] + A[1][1]*B[1][0],
                 A[1][0]*B[0][1] + A[1][1]*B[1][1]]]
    def pow_mat(M, k):
        R = [[1,0],[0,1]]
        while k:
            if k & 1: R = mul(R, M)
            M = mul(M, M); k >>= 1
        return R
    return pow_mat([[1,1],[1,0]], n)[0][1]

# 复杂度: 乘法 O(M(大数位数)) → 总 O(n 位 · log n)
# 这里 n 是步数, 内部 M(数字位数) 可视为常数

export function fibFast(n: number): number {
  // 同上矩阵快速幂;BigInt 在 n 较大时必需
  type Mat = [bigint, bigint, bigint, bigint];
  const mul = (A: Mat, B: Mat): Mat => [
    A[0]*B[0] + A[1]*B[2], A[0]*B[1] + A[1]*B[3],
    A[2]*B[0] + A[3]*B[2], A[2]*B[1] + A[3]*B[3],
  ];
  let R: Mat = [1n, 0n, 0n, 1n];
  let M: Mat = [1n, 1n, 1n, 0n];
  let k = n;
  while (k > 0) {
    if (k & 1) R = mul(R, M);
    M = mul(M, M); k >>= 1;
  }
  return Number(R[1]);
}

7.4 模运算 ​

Zn={0,1,…,n−1}\mathbb{Z}_n = \{0, 1, \ldots, n-1\}Zn​={0,1,…,n−1} 加法模 nnn. 它是环; Zp\mathbb{Z}_pZp​ (ppp 素) 是域.

重要定理 (Fermat 小定理): ap−1≡1(modp)a^{p-1} \equiv 1 \pmod pap−1≡1(modp) (a≢0a \not\equiv 0a≡0).

python
def mod_pow(base: int, exp: int, mod: int) -> int:
    # 平方乘: O(log exp) 次乘法, 全程 mod
    result = 1
    base %= mod
    while exp > 0:
        if exp & 1:
            result = result * base % mod
        base = base * base % mod
        exp >>= 1
    return result

7.5 离散对数 = Crypto 的硬假设 ​

定义: 给定 ggg 与 h=gxh = g^xh=gx in 群 GGG, 求 xxx = DLP.

  • 在 Zp∗\mathbb{Z}_p^*Zp∗​ 上, xxx 大 (e.g. p=2256p = 2^{256}p=2256) 时, DLP ~ O(p)O(\sqrt p)O(p​) (Pollard rho), 仍硬.
  • 在椭圆曲线群 Fp\mathbb{F}_pFp​ 上, DLP ~ O(N)O(\sqrt N)O(N​); 无 sub-exponential 算法 → 同长更安全 → secp256k1, Curve25519.

WARNING

RSA / ECDSA / Ed25519/DH 全部依赖这个"看似可逆但实际不可逆"的指数化. 这就是 Crypto 第十部分的核心. 你之后看出"群 + 离散对数难"就立刻把整条 TLS 1.3 链路看穿.
