3. 概率统计: 分布 / 贝叶斯 / MLE / MAP / 极限 / KL ​

TL;DR ​

工程里的"概率"是刻画不确定性的语言: 你不知道这台机器 next minute 崩不崩, 但你能给一个分布; 你不知道 key 碰撞概率, 但你能算 bound; 你不知道 transformer 学到的 embedding 集中在哪儿, 但你能用 KL 散度告诉它"靠近分布 PPP 别乱漂". 这一篇覆盖:

  1. 概率空间与随机变量 — PSPACE / 离散 vs 连续 / pmf vs pdf / CDF.
  2. 期望 / 方差 / 协方差 — 随机变量的"代数".
  3. 核心分布家族 — Bernoulli / Binomial / Geometric / Poisson / Uniform / Exponential / Normal / Categorical / Multinomial.
  4. 联合、条件、贝叶斯 — Pr⁡(A∣B)=Pr⁡(B∣A)Pr⁡(A)/Pr⁡(B)\Pr(A|B) = \Pr(B|A)\Pr(A)/\Pr(B)Pr(A∣B)=Pr(B∣A)Pr(A)/Pr(B); 一句话逼回去重写不少系统.
  5. MLE / MAP / EM — 数据 → 参数的反推; ML 训练就是 MLE 大写版.
  6. 极限定理: LLN / CLT / 大偏差 — "为什么 N=30 够了 / 为什么 4-sigma rarely".
  7. 熵 / 交叉熵 / KL 散度 — 信息论与 ML 的最小公因子, 见信息论章节.
  8. 万一线性 GC 不可解的不确定: Concentration inequalities — Markov / Chebyshev / Hoeffding.

1.1 三件套 (Kolmogorov 公理) ​

概率空间 (Ω,F,Pr⁡)(\Omega, \mathcal{F}, \Pr)(Ω,F,Pr):

  • Ω\OmegaΩ = 样本空间 (一切可能结果).
  • F⊆2Ω\mathcal{F} \subseteq 2^\OmegaF⊆2Ω = 事件 σ\sigmaσ-代数 (对补、可数并封闭).
  • Pr⁡:F→[0,1]\Pr: \mathcal{F} \to [0, 1]Pr:F→[0,1] 满足:
    1. Pr⁡(Ω)=1\Pr(\Omega) = 1Pr(Ω)=1.
    2. Pr⁡(E)≥0\Pr(E) \geq 0Pr(E)≥0.
    3. 可数可加: 不相交 EiE_iEi​ ⇒ Pr⁡(⋃Ei)=∑Pr⁡(Ei)\Pr(\bigcup E_i) = \sum \Pr(E_i)Pr(⋃Ei​)=∑Pr(Ei​).

随机变量 X:Ω→RX: \Omega \to \mathbb{R}X:Ω→R, 它把"实验结果"映射成数值. XXX 决定概率分布 Pr⁡X(S)=Pr⁡(X−1(S))\Pr_X(S) = \Pr(X^{-1}(S))PrX​(S)=Pr(X−1(S)).

1.2 离散 vs 连续 ​

  • 离散: 概率质量函数 (pmf) pX(x)=Pr⁡(X=x)p_X(x) = \Pr(X = x)pX​(x)=Pr(X=x).
  • 连续: 概率密度函数 (pdf) fXf_XfX​; Pr⁡(a≤X≤b)=∫abfX(x)dx\Pr(a \leq X \leq b) = \int_a^b f_X(x) dxPr(a≤X≤b)=∫ab​fX​(x)dx; pdf 可 > 1.

二、期望与方差 ​

2.1 期望 ​

E[X]={∑xx p(x)离散∫x f(x) dx连续 \mathbb{E}[X] = \begin{cases} \sum_x x \, p(x) & \text{离散} \\ \int x \, f(x)\, dx & \text{连续} \end{cases} E[X]={∑x​xp(x)∫xf(x)dx​离散连续​

线性性 (无论是否独立): E[aX+bY]=aE[X]+bE[Y]\mathbb{E}[aX + bY] = a \mathbb{E}[X] + b \mathbb{E}[Y]E[aX+bY]=aE[X]+bE[Y].

乘积: E[XY]=E[X]E[Y]\mathbb{E}[XY] = \mathbb{E}[X]\mathbb{E}[Y]E[XY]=E[X]E[Y] 仅当 X,YX, YX,Y 独立.

5.4 EM 算法 (Expectation-Maximization) ​

数据有隐变量 zzz 时, 直接解 MLE 解不出. EM 迭代:

  1. E 步: 写完整似然关于当前隐变量后验的期望

    Q(θ∣θ(t))=Ez∣x,θ(t)[log⁡p(x,z∣θ)] Q(\theta | \theta^{(t)}) = \mathbb{E}_{z | x, \theta^{(t)}}[\log p(x, z | \theta)] Q(θ∣θ(t))=Ez∣x,θ(t)​[logp(x,z∣θ)]

应用: GMM (高斯混合), HMM (Baum-Welch), K-means (硬分版本).

5.5 ELBO 与变分下界 ​

log⁡p(x)=log⁡∫p(x,z)dz≥Ez∼q[log⁡p(x,z)]−Ez∼q[log⁡q(z)] \log p(x) = \log \int p(x, z) dz \geq \mathbb{E}_{z \sim q}[\log p(x, z)] - \mathbb{E}_{z \sim q}[\log q(z)] logp(x)=log∫p(x,z)dz≥Ez∼q​[logp(x,z)]−Ez∼q​[logq(z)]

六、极限定理 ​

6.1 大数定律 (LLN) ​

样本均值 Xˉn=1n∑Xi\bar X_n = \frac{1}{n}\sum X_iXˉn​=n1​∑Xi​ 几乎处处收敛到期望 μ\muμ:

Xˉn→a.s.μ \bar X_n \xrightarrow{\text{a.s.}} \mu Xˉn​a.s.​μ

实践: Monte Carlo 取样本越多越逼近. 没有"无法估计方差 → 我就多采样"的工程路径就靠它.

6.2 中心极限定理 (CLT) ​

i.i.d. 期望 μ\muμ 方差 σ2\sigma^2σ2:

n⋅Xˉn−μσ→dN(0,1) \sqrt n \cdot \frac{\bar X_n - \mu}{\sigma} \xrightarrow{d} \mathcal{N}(0, 1) n​⋅σXˉn​−μ​d​N(0,1)

含义: 无论原分布, 样本均值经标准化渐近正态. 这就是正态分布"伞覆盖了一切"的成因; 也是 Bayes 不能免先验的 freq 默认.

例: 一枚硬币 100100100 次, 头数近似正态, μ=50,σ=5\mu = 50, \sigma = 5μ=50,σ=5. 大概率落在 [40,60][40, 60][40,60].

6.3 大偏差 (Chernoff / Hoeffding) ​

LLN 说"最终到 μ\muμ". 但要量化"偏离 ϵ\epsilonϵ 的概率多小":

Hoeffding 不等式 (有界 Xi∈[ai,bi]X_i \in [a_i, b_i]Xi​∈[ai​,bi​]):

Pr⁡[Xˉn−μ≥t]≤exp⁡(−2n2t2∑(bi−ai)2) \Pr\left[ \bar X_n - \mu \geq t \right] \leq \exp\left(-\frac{2 n^2 t^2}{\sum (b_i - a_i)^2}\right) Pr[Xˉn​−μ≥t]≤exp(−∑(bi​−ai​)22n2t2​)

Chernoff bound (Bernoulli): Pr⁡[Xˉn≥(p+ϵ)n]≤e−2nϵ2\Pr[\bar X_n \geq (p + \epsilon) n] \leq e^{-2 n \epsilon^2}Pr[Xˉn​≥(p+ϵ)n]≤e−2nϵ2.

→ 这就是"为什么 100 次抛硬币正反偏离 0.5 不超过 0.1 是 ~5%".

TIP

6-sigma (Six Sigma) 标准 = 6σ6\sigma6σ 容差 ⇒ defect rate < 3.4 ppm = Hoeffding 直接给. 这是工业质检、A/B test 显著性、SLA 错误预算的概率骨架.

6.4 Markov / Chebyshev / 推导链 ​

Markov (最弱):    P[X ≥ a] ≤ E[X] / a               (X ≥ 0)
Chebyshev:        P[|X - μ| ≥ t] ≤ Var X / t²
Hoeffding:        exp(-2 n t²/(b-a)²)                 (i.i.d. 有界)
Chernoff:         exp(-2 n ε²)                          (Bernoulli)

工程代码: 越往下用, 越用得上紧 (依赖越强 → bound 越松).

6.5 Concentration 在 ML / Distributed 的使用 ​

  • ML 中"经验风险 vs 真实风险" gap 用 Hoeffding 量化 (generalization).
  • Distributed 中 quorum W+R>N 的"读到最新写"概率 = majority 经 Chernoff 上界.
  • 测算 hash 冲撞概率 = birthday bound (鸽巢变体).

测两个分布 ppp 与 qqq 的"差异":
